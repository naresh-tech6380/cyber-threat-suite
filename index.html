Cyber Threat Suite

A SOC-style analyzer for IPs, domains, file hashes and Windows logs. Paste an indicator, get a verdict, a MITRE ATT&CK mapping and a report — the way an analyst works, with fixed rules only.

No AI / ML · Rule-based only Verdicts: Clean · Suspicious · Malicious Runs 100% in your browser

How this works: every verdict below comes from plain if–else rules — a local IOC (indicator of compromise) list, VirusTotal-style detection-count thresholds, and pattern checks. Nothing is predicted, trained or guessed by a model, and nothing you paste leaves this page.

    The verdict rules

    Fixed thresholds. Same input always gives the same verdict.

    DetectionsVerdictAnalyst action
    0 / 70CleanNo action. Log and close.
    1 – 9 / 70SuspiciousInvestigate context: who, when, parent process.
    10+ / 70MaliciousContain: block IOC, isolate host, open incident.
    IOC list matchMaliciousOverrides the count — treated as known-bad.

    Detection counts on this page are simulated in the VirusTotal style (engines flagging the indicator out of 70) so the threshold logic can be demonstrated offline, in class, with safe lab indicators only.
